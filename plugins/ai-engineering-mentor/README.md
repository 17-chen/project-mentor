# AI Engineering Mentor Plugin · AI 工程导师插件

这是 Phase 2A 的 Codex Plugin 最小骨架，用于把已经完成的 Project Mentor Skill 包装成更容易发现和安装的插件。

## 计划提供的入口

- **Explain Project（讲解项目）**：理解整个项目的架构、组件和数据流。
- **Explain Code（讲解代码）**：理解指定文件、模块或代码片段。
- **Teach Me（导师教学）**：根据项目和聊天上下文生成阶段性工程课程。

## 当前状态

插件清单和能力定义已经建立；下一步是接入现有 Project Mentor Skill、完成本地安装验证并补充安装说明。当前稳定版本仍是仓库根目录中的独立 Skill。
